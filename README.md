# 에이버리쌤 자료실

릴스 속 나눔 자료(구글 드라이브 PDF)를 모은 링크트리 스타일 페이지예요.
주소: https://jaryo.mylittlechatterbox.net/

## 자료 추가하는 법
1. 드라이브에서 PDF 공유 설정을 **링크가 있는 모든 사용자 · 뷰어**로 바꾸고 링크를 복사해요.
2. 링크의 `/d/`와 `/view` 사이 글자가 `drive` 값이에요.
3. `index.html`의 `RESOURCES` 목록에 블록 하나를 추가해요.
   - `id`는 영어 소문자로 짧게 정해요. 주소 끝에 `#id`를 붙이면 그 자료로 바로 이동해요 (예: `…/#ck`).
   - 버튼 왼쪽 동그라미에는 드라이브 PDF 첫 장 미리보기가 자동으로 들어가요. 못 불러오면 제목 첫 글자가 나와요.
     직접 만든 이미지를 쓰려면 이 폴더에 넣고 `thumb: '파일이름.jpg'`를 적어요.
4. 추가한 날(`added`)부터 10일 동안 NEW 표시가 붙어요.

카드의 ⋮ 버튼을 누르면 그 자료로 바로 가는 링크를 공유하거나 복사할 수 있어요.

자료 목록 원본: 드라이브 「영상별 나눔자료 목록」 문서.
